Governance component patterns

The four reusable primitives. Everything bigger is assembled from these.

1 · Confidence / Gate badge

Live score + which autonomy gate the content is sitting at. Appears anywhere content appears. Thresholds shown: escalate<75 · review<92 · auto-publish≥92.

Hover/click opens the 4-axis "why" explainer (model · verification depth · domain · provenance) — already computed in the codebase.

2 · System mode indicator

Global, unmistakable at a glance. Three system modes + a persistent Manual/HITL override. Lives in the top bar; click opens the mode-control panel (RBAC-gated).

Autonomous Supervised Paused ＋ ✋ Manual override · ON

Autonomous = auto-publish gate active · Supervised = all publishes routed to review · Paused = nothing ships. Manual override pins a piece/project to human regardless of score.

3 · Sign-off control (with role-blocked state)

Every irreversible action shows a pre-state + role check + audit note. The blocked state is designed, not just the happy path.
